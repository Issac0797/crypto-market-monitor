# 市场监控待选方案

2026-10-21；以下均为设计建议，尚未开启、未经历史校准，不是已发现的机会。
2026-10-22最新要求覆盖本提案：先建基础架构，再开发套利和异常检测器，再启动监控。
旧BTC/ETH套利扫描已删除；下表均为后续研究方向，当前无启用中的检测器。
未来策略只有形成明确确定性规则、成本模型和离线验证后，才能标注“符合策略”。
2026-11-10仅5分钟价格异动另行确定候选阈值为1%（恢复0.5%，确认30秒），
见[bot-phase4](bot-phase4.md)；下表中的3%是早期提案，不代表当前配置。

## 标的建议

| 层次 | 建议标的 | 用途 |
|---|---|---|
| 后续范围 | BTC、ETH 的现货和 USDT 永续 | 价格/基差/资金费观察；不绑定旧100 USDT策略 |
| 优先待选 | USDT、USDC | 计价币风险；独立 USD 参照及多来源确认 |
| 第二批待选 | SOL、BNB、XRP | 仅观察行情、资金费与深度，不直接继承现有策略参数 |
| 扩展待选 | DAI/USDS、USDe | 不同机制的稳定币风险，先核实交易场所及独立价格来源 |

不建议第一轮扫描全部小币种：需先按现货/永续同时可用、成交额、双边深度、
点差、上市时间及数据连续性筛选；排除杠杆代币和低流动性异常报价。
名单需定期审核，下架或接口变化要产生数据事件，不静默换标的。

## 异常规则候选

| 规则 | 初始讨论值（不是已验证参数） | 消息性质 |
|---|---|---|
| 稳定币偏离 | 距1 USD偏离≥0.3%持续60秒预警；≥1%严重；至少两个独立来源 | 风险，禁止称为无风险抄底 |
| 价格急变 | BTC/ETH 5分钟绝对收益≥3%，15分钟≥5%；其他币需独立阈值 | 市场异动，尚非策略信号 |
| 基差扩大 | (永续中价/现货中价−1)的绝对值≥1%持续60秒 | 候选观察，需剔除错时/深度不足 |
| 资金费极端或翻转 | 按实际周期换算8小时等效费率；绝对值≥0.1%提醒 | 费率持续为假设，不是实现收益 |
| 流动性骤降 | 点差超过近期中位数3倍且超过绝对门槛，指定金额可成交深度下降≥70% | 风险；需要新深度适配器 |
| 清算/OI突变 | 5分钟清算量或OI变化超过历史分位阈值 | 衍生品压力，需要明确数据覆盖 |
| 交易所/链异常 | 充提暂停、API长时间不可用、链停止、预言机分歧 | 风险；官方来源、资产和链均须明确 |

稳定币采用可成交双边报价、中价及来源时间，分别标注折价/溢价。
USDC/USDT偏离只能解释为相对偏离，不能认定USDC或USDT单独脱锚；
两个来源若共用同一上游也不能视作独立。报价过期、低成交深度、跨链包装资产
身份不明时应报数据不足。法币赎回条款/储备说明不能替代二级市场即时价格。

来源依据：[Circle储备与赎回说明](https://www.circle.com/transparency)、
[Tether透明度](https://tether.to/en/transparency/)、
[Binance公共市场数据](https://developers.binance.com/en/docs/products/spot/rest-api)。
官方发行方锚定目标是参照，本文阈值为工程建议，不来自发行方的保证。

## 通知与验收建议

市场异常采用进入/升级/恢复状态机；初步建议连续确认、恢复阈值小于触发阈值、
恢复持续5分钟、同事件15分钟冷却，严重升级可突破冷却。规则版本和状态均须持久化。
恢复与持续条件按观测时间计算，缺失区间不能假定持续正常。
策略候选和风险消息分开，记录来源、价格、偏离、触发规则、持续时间及有效期。
先用冻结规则做影子监控，统计误报、漏报、延迟及数据缺失，再决定上线范围。

当前待你选择：稳定币是否优先；是否增加SOL/BNB/XRP观察池；
上述哪些异常纳入；是否接受初始讨论阈值。确认前不启用这些规则。
