# 市场监控扩展提案

本文只记录 Crypto Market Monitor 的后续观察方向。它们是设计建议，不代表当前已经
启用、已经验证或已经形成可实现收益。当前运行参数以配置文件和 README 为准。

## 可扩展观察范围

| 范围 | 候选标的 | 用途 |
| --- | --- | --- |
| 当前核心 | BTC、ETH 现货与 USDT 永续 | 价格异动、基差、预计资金费 |
| 稳定币优先 | USDT、USDC、USDe | 美元偏离、来源一致性、流动性 |
| 后续观察 | SOL、BNB、XRP | 需重新验证公共接口、深度和阈值 |
| 暂不纳入 | 低流动性小币、杠杆代币 | 报价稀疏、异常点差和身份风险过高 |

新增标的应先确认现货/永续市场身份、成交额、双边深度、点差、上市时间和数据连续性。
下架或接口变化必须产生数据事件，不能静默替换标的。

## 规则候选

| 规则 | 初期讨论值 | 边界 |
| --- | --- | --- |
| 价格急变 | BTC/ETH 5 分钟 ≥3%、15 分钟 ≥5% | 尚未校准；不得直接照搬现有阈值 |
| 稳定币偏离 | 距 1 USD ≥0.3% 持续 60 秒 | 至少两个独立来源，不能称“无风险” |
| 基差扩大 | 绝对基差 ≥1% 持续 60 秒 | 盘口中价，不是可实现套利利润 |
| 资金费异常 | 8 小时等效绝对值 ≥0.1% | 预计值，不是实现收益 |
| 流动性骤降 | 点差和指定深度同时恶化 | 需要新的深度数据与历史基线 |
| 交易所/链异常 | 充提暂停、API 长时不可用、链停止 | 必须区分来源、资产和链 |

## 数据与通知原则

- 使用可成交双边报价、源时间、盘口价差和深度，不以本机时间补源时间。
- 价格和稳定币事件采用进入、升级、恢复状态机；缺数只能产生 `DATA_STALE`，
  不能据此解除风险。
- 扩大标的或来源前应做影子监控，统计误报、漏报、延迟、缺口和资源使用。
- 普通行情播报与风险事件分离；不要为了让用户看到“活着”而发送心跳刷屏。
- 规则版本、阈值和状态要可追踪，不在运行时静默调参。

本文不包含交易执行、套利下单、钱包签名、私钥管理或任何投资建议。
