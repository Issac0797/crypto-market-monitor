# Bot 通知边界

Bot 专属持久队列、风险生命周期、HTML 转义模板和只读命令随本项目独立维护。
默认只发送行情风险进入、升级、恢复与授权用户主动查询回复；
数据诊断留健康/日志，显式 --data-notifications 可恢复诊断通知。
原配置、消息 ID、Telegram 路由和 SQLite 表结构保持，公开参数不调优。

所有发送需显式 --telegram，目的地与历史绑定一致且在白名单。
单 poller、持久 offset/回复事务、有限重试/429 退避与永久错误失败边界保持；
确认发送到本机标 sent 之间崩溃仍可能重复，不能承诺端到端恰好一次。
